`mdxr render` と `mdxr serve` の HTML には **Annotate** ボタンが表示されます。レンダリング結果を見ながら文章や図にコメントし、Coding Agent に修正を依頼できます。

## 文章にコメントする

1. ドキュメント内の文章を選択します。太字やリンクなど、インラインの装飾をまたぐ選択もできます。
2. **Add comment** を押してコメントを書き、**Save comment** で保存します。
3. 注釈パネルの **Edit** で編集、**Delete** で削除、**Show target** で対象に移動できます。保存した文章は本文でハイライトされます。

文字列を選択した状態で **Ctrl+Shift+M**（Windows/Linux）または **Cmd+Shift+M**（macOS）を押してもコメントできます。**Ctrl+Enter** / **Cmd+Enter** で保存できます。**Escape** でパネルを閉じても入力中の下書きは残りますが、再読み込み後に復元されるのは保存済みのコメントだけです。

## 図にコメントする

**Annotate → Select figure** を開き、本文の画像・図・グラフをクリックします。**Figure** の一覧から対象を選び、**Comment on figure** を押すこともできます。キャプションや画像の代替テキストで対象を確認できます。Mermaid も図の描画後に選択できます。

プロジェクト独自のコンポーネントは、`<figure>` または `data-mdxr-figure` 属性を持つ要素を出力すると、図として選択できます。

## Coding Agent に渡す

**Copy Markdown** で保存済みのコメントをまとめてコピーします。ドキュメントのパス、見出し、引用した文章または図のキャプション、画像パス、コメントが含まれます。元のブロックを一意に特定できた場合は MDX の行範囲も含まれます。`Include` で取り込んだ内容は、取り込み元ファイルのパスと行番号を使います。

```markdown
# Feedback: 実装計画

Document: ` /project/plan.mdx `

Please address the following review comments in the source document.

## 1. Text comment

Source block: ` /project/plan.mdx:12-14 `
Section: エラー処理

> 失敗したリクエストは自動的に再試行します。

**Comment**

再試行の上限回数と、再試行するエラーの条件を明記してください。
```

この Markdown を Coding Agent に貼り付けて修正を依頼します。クリップボードが使えない環境では、手動コピー用の Markdown 欄が表示されます。

## 注釈の保存と文書の更新

保存済み注釈は、同じブラウザー・同じオリジン内でドキュメントのパスごとに保存されます。MDX や HTML ファイルには書き込まれません。HTML を別の人に渡しても注釈は共有されないため、レビューを共有したり別のブラウザーへ渡したりするときは Markdown をコピーしてください。

文書を再レンダリングした後も、対象を特定できる場合は注釈を復元します。対象が変更・削除された場合や複数の候補がある場合は、元の引用を保持し、対象が見つからないことを表示します。この状態でも編集とコピーができ、Markdown には元の選択を参照している旨が含まれます。

ブラウザーの保存機能が使えない場合も、開いている間は注釈とコピーができます。パネルに保存失敗が表示された場合は、ページを閉じる前に Markdown をコピーしてください。印刷時には注釈 UI は表示されません。注釈機能は React のハイドレーションに依存しないため、`--no-hydrate` でも利用できます。
