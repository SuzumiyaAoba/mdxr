## Requirements

- Node.js 20 or newer

## Render your first document

<Steps>
  <Step title="Write a document">

    Create `plan.mdx` — plain Markdown plus mdxr components:

    ```mdx plan.mdx
    ---
    title: Migration plan
    status: doing
    owner: "@you"
    ---

    :::goal
    Ship the new renderer behind a flag.
    :::

    :::phase{title="Phase 1 — scaffolding" status="doing"}

    <Steps progress>
      <Step status="done">Compile MDX</Step>
      <Step status="doing">Wire up hydration</Step>
      <Step status="todo">Ship it</Step>
    </Steps>

    :::
    ```

  </Step>
  <Step title="Render it">

    ```sh
    npx @suzumiyaaoba/mdxr render plan.mdx --open
    ```

    Writes `plan.html` next to the document and opens it in your default browser. The HTML is standalone — CSS and the hydration bundle are inlined — so the file works anywhere.

  </Step>
  <Step title="Preview while you edit">

    ```sh
    npx @suzumiyaaoba/mdxr serve plan.mdx --open
    ```

    A live-reloading preview at `http://localhost:3737`. Saves rebuild instantly; config and theme changes are picked up too.

  </Step>
</Steps>

## Read it in the terminal

`mdxr text` renders the same document to plain Markdown — components become ASCII stand-ins (checkbox lists, block-bar charts, GFM tables, `<details>` disclosures):

```sh
npx @suzumiyaaoba/mdxr text plan.mdx      # → plan.txt.md
```

## Set up your agent

```sh
npx @suzumiyaaoba/mdxr init               # Codex + Claude, in your home directory
npx @suzumiyaaoba/mdxr init --local       # add instructions to this project
```

Then ask your agent to write an implementation plan or report and render it with mdxr. See [Agent setup](/agent-skill) for tool-specific options and the bundled Agent Skill.
