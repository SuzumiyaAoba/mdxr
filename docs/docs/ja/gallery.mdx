以下の例はすべて [`examples/`](https://github.com/SuzumiyaAoba/mdxr/tree/master/examples) ディレクトリにある実際の `.mdx` ドキュメントで、ドキュメントサイトのビルド時に `mdxr render` でレンダリングしています。プレビュータブは実際の出力そのもの — ハイドレーション込みなのでフレーム内でインタラクティブなコンポーネントも動作し、コードタブではそのソースを確認できます。
