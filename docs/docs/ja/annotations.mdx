`mdxr render` と `mdxr serve` の HTML には **コメント** ボタンが表示されます。レンダリング結果を見ながら文章や図にコメントし、Coding Agent に修正を依頼できます。

## 文章にコメントする

1. ドキュメント内の文章を選択します。太字やリンクなど、インラインの装飾をまたぐ選択もできます。
2. **コメントを追加** を押してコメントを書き、**コメントを保存** で保存します。
3. コメントパネルの **編集** で編集、**削除** で削除、**対象箇所を表示** で対象に移動できます。保存した文章は本文でハイライトされます。

文字列を選択した状態で **Ctrl+Shift+M**（Windows/Linux）または **Cmd+Shift+M**（macOS）を押してもコメントできます。**Ctrl+Enter** / **Cmd+Enter** で保存できます。**Escape** でパネルを閉じても入力中の下書きは残りますが、再読み込み後に復元されるのは保存済みのコメントだけです。

## 図にコメントする

**コメント → 図を選択** を開き、本文の画像・図・グラフをクリックします。**図** の一覧から対象を選び、**図にコメント** を押すこともできます。キャプションや画像の代替テキストで対象を確認できます。Mermaid も図の描画後に選択できます。

プロジェクト独自のコンポーネントは、`<figure>` または `data-mdxr-figure` 属性を持つ要素を出力すると、図として選択できます。

## Coding Agent に渡す

**Markdown をコピー** で未対応のコメントをコピーします。**チャットへ送信** では、未対応のコメントを開いている Coding Agent に送信します。どちらもドキュメントのパス、見出し、引用した文章または図のキャプション、画像パス、コメントが含まれます。元のブロックを一意に特定できた場合は MDX の行範囲も含まれます。`Include` で取り込んだ内容は、取り込み元ファイルのパスと行番号を使います。対応済みのコメントは一覧に残り、再度未対応にしない限り送信されません。

```markdown
# Feedback: 実装計画

Document: ` /project/plan.mdx `

Please address the following review comments in the source document.

## 1. Text comment

Comment ID: ` review-123 `

Source block: ` /project/plan.mdx:12-14 `
Section: エラー処理

> 失敗したリクエストは自動的に再試行します。

**Comment**

再試行の上限回数と、再試行するエラーの条件を明記してください。
```

この Markdown を Coding Agent に貼り付けて修正を依頼します。クリップボードが使えない環境では、手動コピー用の Markdown 欄が表示されます。

## コメントの対応状況を管理する

コメントは最初 **未対応** です。**すべて・未対応・対応済み** で一覧を絞り込めます。コメントを **対応済み** にすると、表示中の文書の revision と対応日時が記録されます。`mdxr serve` のワークスペースでは、対応した保存版とプレビューへのリンクも記録します。単独でレンダリングした HTML では revision と日時を記録し、プレビューリンクは表示しません。コメント本文を編集すると未対応に戻り、次の依頼に含められます。

Markdown のコピーや Coding Agent への送信後も、現在のコメントは一覧に残ります。履歴には実際にコピー・送信した未対応コメントのスナップショットを、当時の状態とともに保存します。後から行った編集や状態変更は過去のスナップショットに反映されません。

## 注釈の保存と文書の更新

保存済みコメントと過去のコピー・送信履歴は、同じブラウザー・同じオリジン内でドキュメントごとに保存されます。現在の一覧から削除したコメントは再読み込み後も復活しませんが、過去の履歴は残ります。コメントは MDX や HTML ファイルには書き込まれず、HTML を別の人に渡しても編集中のコメントは共有されません。レビューを共有したり別のブラウザーへ渡したりするときは、未対応コメントの Markdown をコピーしてください。

文書を再レンダリングした後も、対象を特定できる場合は注釈を復元します。対象が変更・削除された場合や複数の候補がある場合は、元の引用を保持し、対象が見つからないことを表示します。この状態でも編集とコピーができ、Markdown には元の選択を参照している旨が含まれます。

ブラウザーの保存機能が使えない場合も、開いている間は注釈とコピーができます。パネルに保存失敗が表示された場合は、ページを閉じる前に Markdown をコピーしてください。印刷時には注釈 UI は表示されません。注釈機能は React のハイドレーションに依存しないため、`--no-hydrate` でも利用できます。
